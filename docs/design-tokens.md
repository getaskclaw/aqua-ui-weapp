# 设计令牌 Design Tokens

全部色值附带实测 WCAG 对比度(白字/底上下文字)。对比度门槛:按钮大字 ≥3:1,正文 ≥4.5:1。

## 结构色

| Token | 值 | 用途 | 实测 |
|---|---|---|---|
| `--navy` | `#162455` | 顶栏/底栏/深色 hero(框) | 其上 `#b8e6fe` 文本 11.1:1 |
| `--navy-deep` | `#091444` | navy 加深档 | — |
| `--aqua` | `#13ecf3` | **仅 navy 底上**(选中态/CTA) | 压 navy 12.0:1;压白底 1.6:1(禁用) |
| `--bg` | `#eef4f7` | 页面浅底 | — |
| `--ink` | `#0b2230` | 主文字(带青调的非黑) | 压浅底 14.9:1 |
| `--sub` | `#41626f` | 次级文字 | 压浅底 4.9:1 |

## 主色阶(青)

| Token | 值 | 用途 | 实测 |
|---|---|---|---|
| `--p500` | `#12bcd0` | 点缀/图标/描边 | 不压白字 |
| `--p600` | `#0aa0b4` | **主按钮**(唯一) | 白字 3.1:1 |
| `--p700` | `#088896` | 按压/强调 | 白字 4.2:1 |

## 语义色(跨端同源,永不动)

| Token | 值 | 语义 |
|---|---|---|
| `--ok` | `#1c7c54` | 已确认 (4.8:1) |
| `--warn` | `#b3541e` | 待复核/待办 (4.7:1) |
| `--danger` | `#b00020` | 危险/失败 |
| 次级 | `#6b7a8c` | 已结案/驳回 |

## 材质

- `.mesh` — 三团弥散渐变(`#7fdcee` / `#9fe8d8` / `#b9d9f5`)+ 线性浅底
- `.glass` — `rgba(255,255,255,.45)` + `backdrop-filter: blur(24px) saturate(1.4)` + 1px 高光边 + 26rpx 圆角 + 软阴影;旧机自然降级为半透明卡
- dock — 悬浮胶囊:fixed 底部,玻璃材质,圆角 52rpx
